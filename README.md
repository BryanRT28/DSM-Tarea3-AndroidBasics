# Desarrollo de Sistemas Móviles — Tarea 3: Interactúa con la IU y el Estado

Este repositorio contiene la resolución integral de las **Rutas 1, 2 y 3 de la Unidad 2** de Android Basics with Compose, desarrollada en Android Studio y Kotlin.

---

## Estructura del Repositorio

* **`ruta1-kotlin/`**: Ejercicios prácticos de lógica, colecciones, lambdas y funciones de orden superior en Kotlin.
* **`ruta2-kotlin/`**:
  * `DiceRoller/`: Aplicación de lanzamiento de dados interactiva usando `remember` y `mutableStateOf`.
  * `Lemonade/`: Práctica de máquina de estados secuenciales finitos orientada a eventos de clic.
* **`ruta3-kotlin/`**:
  * `TipTime/`: Calculadora de propinas con patrón *State Hoisting*, componentes *stateless* y pruebas unitarias automatizadas con JUnit.
  * `ArtSpace/`: Proyecto integrador de galería de arte con navegación cíclica continua.
